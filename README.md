## Featured Projects

- 🛡️ **ChatSecOps** *(Graduation Thesis)* — Autonomous ReAct agent on Gemini function calling with 8 threat-intel tools (VirusTotal, Shodan, OTX, MITRE ATT&CK mapping…), natural-language-to-SQL over a SQLite memory layer, and a LightGBM malicious-domain classifier (99.75% accuracy) with SHAP explainability.
- 🔗 **FL + Blockchain Poisoning Defense** — Adaptive Gamma penalty and reputation-based weighted voting for blockchain federated learning; sustained >99% accuracy under 40% poisoning (baseline: 64%).
- 📊 **Causal-DGS-SMOTE** *(co-author, in development)* — Oversampling algorithm combining DirectLiNGAM causal discovery with density-guided sampling; beat SMOTE, Borderline-SMOTE and ADASYN on F1 in 5 of 7 datasets.
- 😴 **DrowsyNet** *(TÜBİTAK)* — MobileNetV2-based driver drowsiness detection, 91.15% validation accuracy.
